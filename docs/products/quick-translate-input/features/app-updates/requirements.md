# アプリの自動更新

## このドキュメントについて

[Quick Input Translator](../../product.md)の利用者が、手動でアプリを入れ直さずに更新するための条件を定める。
更新のたびにアクセシビリティ権限を登録し直す負担を減らす。

### スコープ

配布版の更新確認、ダウンロード、終了時の適用、手動確認、自動更新の設定を扱う。
有料のApple Developer Programには加入せず、固定した自己署名証明書で配布する。

### スコープ外

初回インストール時のmacOSの警告をなくすこと、既存の仮署名版から権限を引き継ぐこと、macOSの権限設定を自動で書き換えることは扱わない。
開発用ビルドを配布版に自動で置き換えない。

## ユーザーストーリー

### 入れ直さずに新しい版を使う

利用者として、普段の作業を続けながら更新を受け取り、アプリを終了した後に新しい版を使いたい。

**受け入れ条件:**

Scenario: 新しい対応版がある場合、終了時に更新を適用する

- Given: 自動更新が有効で、現在より新しい対応版が公開されている。
- When: アプリが更新を確認し、利用者がその後アプリを終了する。
- Then: 正しい配布元の更新をダウンロードして終了時に適用し、次回起動時は新しい版を使える。翻訳中にアプリを強制終了しない。

Scenario: 同じ証明書で更新した場合、設定と権限を維持する

- Given: 固定証明書の配布版にアクセシビリティ権限を付与し、言語とトリガーを保存している。
- When: 同じ証明書と識別子で署名した新しい配布版へ更新する。
- Then: 保存した設定を読み込み、権限の再登録なしに外部入力欄で翻訳できる。

Scenario: 更新を検証できない場合、現在のアプリを維持する

- Given: 配信情報またはダウンロードした更新が改ざんされている。
- When: アプリがその更新を確認する。
- Then: 更新を適用せず、現在の版を使い続けられる。手動確認では失敗の理由を表示する。

### 自分で更新方法を選ぶ

利用者として、自動更新を止めたり、必要なときに更新を確認したい。

**受け入れ条件:**

Scenario: 自動確認を無効にした場合、手動操作で確認できる

- Given: 自動確認を無効にしている。
- When: メニューから更新確認を選ぶ。
- Then: 新しい版の有無を確認して結果を表示する。無効にした設定は再起動後も残る。

Scenario: 通信できない場合、翻訳を続けられる

- Given: インターネットへ接続できない。
- When: 更新を確認する。
- Then: 現在のアプリを維持する。翻訳機能や保存済みの設定は変更しない。

Scenario: 開発用ビルドの場合、配布版に自動で置き換えない

- Given: 開発用の署名でビルドしている。
- When: アプリを起動する。
- Then: 配布版の自動更新を開始せず、更新用のメニューを表示しない。

## KPI

### 更新後の再登録

- **現状値:** 利用者から、curlでの更新ごとに権限が外れるとの報告がある。発生率は未計測。
- **目標値:** 同じ署名元の配布版を更新する際の権限再登録を0回にする。
- **計測方法:** 更新前後に外部入力欄での翻訳と設定の維持を確認する。
- **計測期間:** 初回の配布版切り替え後、連続する2つの配布版の更新時。

## 機能要件

### 更新を確認して適用する

**概要:** 新しい対応版を定期的に確認し、自動更新が有効ならダウンロードして終了時に適用する。

**入力:** 公開された更新情報、自動確認と自動適用の設定、手動の確認操作。

**出力:** 更新済みのアプリ、または更新の有無と失敗の表示。

#### 適用する条件

自動確認と自動適用は初期状態で有効にし、利用者がそれぞれ変更できる。
同じか古い版、対応しないOSやCPU向けの版は適用しない。
再起動を伴う即時更新は利用者が選び、通常の自動適用はアプリの終了まで待つ。

#### 例外ケースでの振る舞い

権限不足などで自動適用できない場合は、更新画面で必要な操作を案内する。
通信や検証に失敗しても現在のアプリを置き換えない。
仮署名版から固定証明書へ切り替える初回だけ、権限の再登録が必要であることを案内する。

## データ要件

### 必要なデータ

- **更新情報:** 版、対応環境、ダウンロード先、署名。
- **更新設定:** 自動確認と自動適用の選択、確認時刻、スキップした版。
- **署名情報:** 更新前後で同じ配布元であることを確認する情報。

### データ間の関係

更新情報は特定の配布版を指し、更新設定はアプリを利用するMacのユーザーごとに保持する。

### 個人情報

翻訳対象の文章や入力内容を更新先へ送信しない。
更新先には通常の通信に伴うIPアドレスなどと、アプリやOSの版が伝わる。追加の利用統計は送信しない。

## 依存する外部サービス

- **GitHub Releases**
  - **関連するユーザーストーリー:** 入れ直さずに新しい版を使う。
  - **依存する理由:** 配布版と更新情報の配信に使う。
  - **契約・利用上の判断:** 既存の公開リポジトリの配布先を継続し、新たな有料契約を追加しない。

## セキュリティ上の留意事項

配布元を検証できる更新だけを適用する。
署名用の秘密鍵をリポジトリや配布物へ含めない。
署名元の変更を通常の更新として公開しない。

## 未決事項

なし。自己署名での権限維持は、上記の受け入れ条件に従って実機で検証する。
